# Sketch 001: Dice Reveal

## Design Question
Which of the three named directions (warm tavern, sleek casino, playful cartoon house) feels right for the highest-stakes moment in the product — the Liar's Dice challenge reveal on the TV?

## How to View
```
open .planning/sketches/001-dice-reveal/index.html
```

Use the **Director** row under each variant to step through the four real stages (Claim → Board → Counting → Verdict), or hit **▶ Play full sequence** to watch it run at roughly the real timing (claim ~2.2s, then the dice board settles, then a ~450ms-per-die counting glow, then the sticky verdict). All three variants show the identical scripted round — same players, same bid, same outcome — so the comparison is purely visual, not content.

## Variants
- **A: Tavern** — candlelit wood tones, parchment text, amber/ember glow, serif display type (Cormorant Garamond).
- **B: Casino** — near-black, metallic gold + emerald, crisp geometric type (Space Grotesk), high contrast.
- **C: Cartoon House** — storybook-dusk purple with candy-bright pink/teal/yellow accents, bouncy rounded type (Baloo 2).

## What to Look For
- Does the **claim text** read clearly from across a room in each theme?
- Does the **counting glow** feel exciting or just busy? Try "Play full sequence" rather than clicking stages one at a time — the counting only really lands with the timing.
- Does the **verdict overlay** feel like a genuine "moment," or does it get lost against the board behind it?
- Which theme feels most like *your* Go Home, independent of Liar's Dice specifically — this same palette will eventually carry the lobby, Home, and every future game.

# Sketch 002: Dice Reveal, Refined

## Design Question
Cartoon house is out. Tavern needs more life (less "old sepia gangster photo"). Casino needs more warmth, more green, and the gold should feel like an active character, not a static color. Plus one new direction: Pirates of the Caribbean / Davy Jones' ship — the closest real-world reference point you have for this game.

## How to View
```
open .planning/sketches/002-dice-reveal-refined/index.html
```

Same scripted round as sketch 001 (same players, bid, and outcome), so the only variable is the visual treatment. Use **Director → Play full sequence** on each tab — the casino and pirate variants specifically have new *motion* (a pulsing gold glow, a ghostly teal pulse, a faint ship sway) that a static screenshot won't show you.

## Variants
- **A: Tavern (warmer)** — same wood-and-candlelight family as before, but lighter and more saturated: a coral-red pop instead of somber burnt-orange, brighter cream text, and a fresh sage-teal accent so it isn't one note of brown anymore.
- **B: Casino (warmer + gold)** — background shifted from cold blue-black to a bottle-green-black; gold is now an active character — it pulses on the counted dice and on the verdict text instead of sitting still.
- **C: Pirate / Davy Jones** — new direction. Deep ocean night, barnacled dark wood, weathered brass, an eerie bioluminescent teal glow standing in for firelight/gold, a blackletter pirate display face (Pirata One), and a barely-there sway on the whole screen like a ship at anchor.

## What to Look For
- **Tavern**: does it now read as "cozy game night" rather than "whiskey noir," without losing the tavern identity entirely?
- **Casino**: is the green mix noticeable but not muddy? Does the gold pulse feel exciting or distracting once you've watched it a few times?
- **Pirate**: does the ship-sway read as atmospheric or as a bug? Is the teal glow legible against the dark background from a TV-distance squint?
- Overall: which one do you want to see fleshed out into the lobby/arrival screen next?
